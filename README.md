# 快打英雄 Street Heroes（網頁版）

20 位原創角色的 2D 對戰格鬥遊戲（Godot 4.7 匯出），角色、美術、音樂皆為原創。

▶ 直接玩：https://kevinchang0531.github.io/street-heroes/

- 單人闖關 5 關（隨機 4 位對手＋暗影分身），或同一台鍵盤雙人對戰
- 1P：A D 走、W 跳、S 蹲、J 拳、K 腳、L 必殺（或 ↓→＋J），往後退＝防禦
- 2P：方向鍵＋數字鍵 1 2 3（或 , . /）
- Esc 暫停、M 開關音樂；分數只存在自己的瀏覽器
- 單人模式畫面上有方向鍵與拳／腳／大招按鈕，手機、平板也能玩；電腦用鍵盤或滑鼠都可以
